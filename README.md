### First "Big" Python Project

Automation intended to process data exported from a plate reader software called SoftMax Pro7 via the following ways:

* Input:
  * a csv file that contains labels for each sample present in a 96-well plate
  * the raw data from the softmax pro7 software
* Output:
  * An excel file that contains the linear, logarthimic and/or 5-Parameter Logistic regression model values, interpolation of unknowns when provided a set of standards and a matplotlib line graph
  * A graphpad prism file with a preset column scatter plot that contains the optical density values from the raw data

This project allowed me and my fellow lab technicians to expedite our workflow and test larger volumes of samples without having the data processing being the bottleneck.
